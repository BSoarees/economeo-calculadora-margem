# Economeo — Margem por plano

Calculadora de unit economics para comparar os planos do Economeo na mesma base: **lucro por cliente por mês**.

## O que ela calcula

- Mensal no cartão, anual no Pix e anual no cartão.
- Custo por mensagens no WhatsApp e leituras com IA.
- Taxas de gateway, parcelamento e antecipação.
- Margem de contribuição e lucro após rateio da estrutura fixa.
- Ponto de equilíbrio de cada plano.

## Como abrir

Abra [`dist/index.html`](dist/index.html) em qualquer navegador. Não é necessário instalar dependências.

Os cenários ficam armazenados somente no `localStorage` do navegador. Nenhum dado financeiro é enviado para um servidor.

## Antes de decidir preços

Os valores iniciais são ilustrativos. Substitua pelas taxas reais do gateway, Meta/WhatsApp, provedor de IA e custos do Economeo.
